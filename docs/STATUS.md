## What it takes to run on its own (not set up yet)
Today everything is files on this computer; nothing runs by itself and no alerts are sent.
- **Where the data lives:** `site/src/data/releases.json` (release pages, forecasts, evidence), `site/src/data/history.json` (version history and support dates), `site/updater/log.json` (every updater run: changes, review items, failed feeds). These are plain files; a git repository should be the backup and history (the folder is not a git repo yet). A database (for example Cloudflare D1) is only needed later for the marketplace (accounts, listings, click counts).
- **Needed to run daily:** (1) a GitHub repo for the code and data; (2) a scheduled job (GitHub Actions, free) that runs `npm run update -- --write`, then `npm test`, commits the data and triggers a rebuild; (3) hosting for the static site (Cloudflare Pages or Netlify, free tier) that rebuilds on each commit; (4) a domain.
- **Alerts (planned):** the daily job would send the updater's "for the owner to review" list and any failed feeds to the owner, by email or Telegram bot (needs a bot token or email service key from the owner), and open a GitHub issue for anything that needs a decision. A weekly summary (pages added, forecasts graded, Search Console numbers) is the next step.
- **Owner accounts needed:** GitHub, hosting (Cloudflare or Netlify), domain registrar, Google Search Console, Bing Webmaster Tools (for IndexNow), and the alert channel.
